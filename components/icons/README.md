# components/icons

Jeu de 18 icônes SVG dessinées sur mesure (trait 1,5px, grille 24×24) :
clé-usb, plateforme, agent-ia, code, automatisation, veille, maintenance,
livraison, paiement, whatsapp, panier, devis, formation, vidéo, pdf,
utilisateur, cadenas, flèche.

Aucun emoji, aucune icône générique importée brute d'une bibliothèque : c'est
la seule source d'icônes autorisée dans tout le projet (voir Principe n°1,
`PLAYBOOK-CONSTRUCTION.md`).

Construit à l'Étape 4 du playbook.
